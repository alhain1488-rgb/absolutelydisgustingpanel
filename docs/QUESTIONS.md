## Зафиксированные решения / для сведения

### Hysteria2 не поддерживается в MVP
Hysteria2 — QUIC-протокол проекта Hysteria; его сервер **не реализован в
xray-core**, поэтому он не может быть inbound-ом в `config.json` Xray. В
SSH-конфиг-механизме MVP он не поддерживается. Реестр протоколов спроектирован
так, чтобы адаптер Hysteria2 (поверх отдельного бинарника hysteria / sing-box)
можно было добавить позже без изменения схемы БД. Если Hysteria2 нужен —
требуется явное решение человека о запуске отдельного демона на нодах.

## Требует человека (из ROADMAP §«Что требует человека»)

1. Заполнение `.env` реальными секретами (`PANEL_ENCRYPTION_KEY`,
   `PANEL_JWT_SECRET`, логин/пароль админа, `PANEL_DOMAIN`).
2. Реальные SSH-ключи и доступ к VPS. Разработка/тесты — только на моках и
   локальной dockerized-ноде Xray.
3. DNS/домен и выпуск TLS (Caddy авто-выпустит при корректном DNS на VPS).
4. Решение по Hysteria2 (см. выше), если нужен.
5. Финальный деплой на прод — после ревью человеком.
